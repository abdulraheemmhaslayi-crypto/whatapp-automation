A 500 page that inherits the shell would silently lose its nonce, its navigation and its user, and any template logic touching `request` would render blank. Worse, the error page is the one page that must never itself raise. So: no `request`, no inline script, no context processor output. Only {% static %}, which needs none of them. {% endcomment %}
